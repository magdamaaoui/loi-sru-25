# Preparedness project photographs

Web copies of the 11 JPEGs supplied in `photos chantier docar films/`, ordered by the original numeric filename suffix. Each image has 960px and 2200px WebP versions, with EXIF orientation applied. Originals are unchanged.

The page uses placeholder lorem ipsum captions. Descriptive alt text is kept separately in `src/lib/data/preparedness-photos.ts`.
